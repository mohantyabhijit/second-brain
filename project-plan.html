Autonomous research agent roadmap

Turn saved links into a thinking system.

This project starts with unread X bookmarks and YouTube videos, then grows into a personal research agent that reads, summarizes, connects ideas, and sends a daily 5pm digest.

Core intent

The UI here is only the presentation layer. The actual product plan is about ingestion, transcript extraction, source-grounded summaries, cross-source synthesis, digest generation, feedback learning, and later multi-user support.

Roadmap

The phases are sequenced to validate source access first, then add memory, synthesis, automation, and finally user isolation.

Functional Gist

The product is a pipeline. Each stage should be testable without depending on the final UI.

01 Input

Saved sources

X bookmarks, YouTube videos, and later notes from Apple Notes, WhatsApp, Obsidian, screenshots, and scribbles.

02 Extract

Raw material

Tweet text, author metadata, video metadata, transcripts, timestamps, captions, and original source URLs.

03 Understand

Structured notes

Summaries, quotes, notable insights, entities, topics, best video moments, and confidence notes.

04 Connect

Theme graph

Related tweets and videos are clustered so the system can surface patterns instead of isolated summaries.

05 Deliver

Personal digest

A 5pm email turns saved material into a short, useful newsletter with feedback signals for learning.

Feasibility And Risks

These are product constraints, not UI details. They should drive the first implementation decisions.

X bookmark access

X supports bookmarked post lookup through the X API for the authenticated user, but it requires approved developer access and user OAuth scopes including bookmark read, tweet read, and users read.

YouTube Watch Later access

YouTube's official API documentation says some playlists cannot be listed, including Watch Later. The MVP should verify this directly, then fall back to a dedicated playlist or manual link import if blocked.

Transcript coverage

Captions may be unavailable, private, auto-generated, multilingual, or restricted. The system should store transcript status and avoid pretending every video has a complete transcript.

Source-grounded summaries

Every insight must trace back to an original tweet, quote, or video timestamp. This avoids a generic AI digest that cannot be trusted later.

Acceptance Criteria

Each phase has a concrete finish line so the project does not collapse into an abstract second-brain platform.
